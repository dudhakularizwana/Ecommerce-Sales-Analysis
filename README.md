# E-Commerce Sales Analysis

## Overview

This project analyzes e-commerce sales data using Python and explores sales performance, product information, prices, and customer ratings.

The analysis is performed using a Jupyter Notebook.

## Objectives

- Analyze e-commerce sales data
- Understand product and category performance
- Analyze prices and customer ratings
- Calculate and explore sales/revenue information
- Create visualizations to understand the data
- Identify useful business insights

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The project uses an e-commerce sales dataset containing information related to products, categories, prices, sales, and customer ratings.

## Project Workflow

1. Load the dataset
2. Explore the data
3. Clean and prepare the data
4. Analyze products and categories
5. Analyze sales and revenue
6. Analyze customer ratings
7. Create visualizations
8. Extract useful insights

## Project Outputs

The project produces:

- Data exploration and summary results
- Sales and revenue analysis
- Product and category analysis
- Price analysis
- Customer rating analysis
- Graphs and visualizations
- Business insights based on the analyzed data

## Project File

- `ecommerce_sales_dataset.ipynb` – Jupyter Notebook containing the complete analysis

## Conclusion

This project demonstrates how Python and data analysis techniques can be used to understand e-commerce sales data and generate meaningful insights from the dataset.
